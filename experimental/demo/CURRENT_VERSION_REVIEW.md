# 0.4.1 历史版本审阅与修复

当前 0.5.0 的新增反例修复见 [HSCC 修复报告](HSCC_FIXES.md)。本文保留当时版本和证据，不作为最新版本验收。

审阅日期：2026-11-15。交付版本：**FAIRY 0.4.1，Runtime schema 4**。

结论：本轮在原有 183 项测试通过的基础上，实际复现并修复了恢复、资源边界、操作归属、输入契约与执行预算问题。修复后 **274 项测试全部通过**，三路独立审阅完成，当前未发现阻塞既定工程闭环的问题。这是有范围和证据的审查结论，不能解释为对任意输入或农艺科学有效性的绝对证明。

## 审阅依据与范围

按用户最新要求：L3 必须与 L1 共用新骨架；原始 test 与 test_Knowledge 仅提供审计参考；不自动移入 detail/library、Oracle 提示、潜在产量排名或历史流程综合评分。最终任务验收采用工程闭环、收获入库与资源约束。

检查覆盖 `fairy/acps`、`fairy/events`、`fairy/agents`、`evaluate`、`interface/cli`、测试、打包数据和运行产物。主线程与三个子智能体分别审查恢复/事件、物理/生物过程、Agent/指标/证据，再对整合结果独立复核。参考快照中的 14 项源文件哈希与既有来源记录吻合；运行不导入这些快照。

## 架构与遗留机制结论

| 检查项 | 结论 |
| --- | --- |
| L1/L3 是否统一 | 共用同一个 Runtime、注册表、执行循环、产物、恢复与严格回放；场景选择评价器与后端能力 |
| ontology 与后端边界 | ontology 声明对象身份与操作；事件运行时管理时间和事务；biology 管理土壤/作物；physical 管理作业与物料；机械回收已归位 |
| 多后端 | Native/WOFOST 的 L1 共用场景与公共操作；WOFOST 自有水分/生长状态，不叠加 Native；L3 WOFOST 显式拒绝 |
| 观测与推进 | 普通读取不推进时间；有时长/能耗的装备观测声明为作业；日更新只在跨本地午夜结算 |
| 拒绝与事务 | 非法参数与业务拒绝不改变物理状态；跨日作业失败统一回滚；已发生事件与调度描述区分 |
| LLM 可见信息 | 任务、公共对象/约束、工具契约、公开观测与成功回执汇总；没有 audit、恢复包或隐藏籽粒库 |
| Oracle 权限 | 精确的内置策略类型才可取得 Runtime，产物标记特权；真实模型操作 actor 为 agent |
| 旧 App 机制 | 没有导入旧 App/旧控制器，没有自动文件扫描或 import 副作用注册；按对象显式绑定操作 |
| detail/library/知识注入 | 当前任务和默认上下文未引入相关模式、Oracle 轨迹或农艺操作处方 |
| 产量与损失 | 内部干物质用于过程和守恒；模拟入库重量是库存结果；没有 biological-yield/FOS/gap/经济综合分参与成功判定；未测损失只用于审计 |
| 恢复/回放 | 恢复不调用模型；Native 读取状态并检查历史结构，WOFOST 按固定输入重建一次；严格回放新建实例重新执行请求并比较 |
| 打包与依赖 | Native 可在无可选依赖、无 reference 的隔离 wheel 中运行；WOFOST 离线参数也通过打包后运行/回放验证 |

## 兼容性和仍未覆盖的能力

- 恢复格式升级为 **schema 4**，Native season/physical 模型能力版本升级为 **2**。旧快照保持原状，可 inspect；不能直接恢复为当前版本。应重新运行，而不能修改版本标记伪装兼容。
- [0.4.0 L3 真实模型实验](L3_NEW_RUNTIME.md) 是 v3 真实全季前缀与 v4 真实续跑，属于历史证据。本轮没有重新完成 **0.4.1 的真实模型全季 L3**；本轮当前版本的真实模型证据限于 L1，L3 当前版本由 Oracle、模拟模型、恢复与回放验收。
- Native L3 为未校准的简化模型。未移植氮素、病虫害、施药、详细器官碳分配、光周期或原版全部农艺过程；不能据模拟入库公斤数推断真实产量。
- 当前回收率是显式固定参数。没有动态裂荚、倒伏、收获延迟损失、机况损失和储藏劣变模型，暂不能据此评价这些收获策略的优劣。
- 当前仅单地块、固定 64 垄。作业串行且原子完成，没有并行资源竞争、途中恢复或实时装备通信。燃油是聚合库存；拖车/容器是账本中的被动物料位置，尚未建成独立空间实体。
- 恢复包为受信任的本地格式。新增校验用于一致性，未提供签名或任意恶意篡改防护；证明物理重现必须严格 replay。Python 扩展代码属于可信执行环境。
- Oracle 搜索有候选上限，WOFOST 每个候选仍需重建历史。外层墙钟预算在调用边界检查，不是对单次决策/引擎计算的强制抢占。
- 验证环境为本机 Python 3.14/PCSE 6.0.13；未覆盖所有声明的 Python 版本、操作系统或模型服务实现。

上述限制已公开列明，不能作为“已经移植”的能力。下一轮扩展应以新过程的独立验证证据为准。
