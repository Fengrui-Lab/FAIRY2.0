两个过程模块直接移入本目录，删去独立演示入口。土壤引擎增加可选日参考蒸散输入，供 2.0 使用场景声明的 ET0；未传入时保留原版估算。运行不依赖历史仓库。

- **土壤**：灌溉和降雨先进入 100 mm 表层，经入渗上限、重力排水与非饱和再分配补给独立根区；蒸发取自表层，蒸腾取自根区。账本分别记录灌溉损耗、未捕获降雨与径流、深排水及蒸散。表层与根区起始 VWC 取场景初态，两层储量一并参与守恒。保留场景水力分区；根区蒸腾默认沿用原版 0.18 VWC 胁迫阈值，若场景的持水量或萎蔫点与默认阈值冲突，则约束在可用水范围内。
- **生长**：原版黑农58 的冠层、密度惩罚、胁迫指数及辐射利用过程替代 2.0 先前的简化公式。采用原版调度器实际使用的日末根区 VWC 胁迫斜坡（0.12–0.18）。运行使用 2.0 的 GDD 阶段与进度输入，统一的营养期映射至原版 V4+；并未移植原版光周期和出苗流程。使用原版成熟收获指数，R8 时把模型籽粒估计作为毛干粮库存，继续由 2.0 记录收获回收损失、干燥和实际入库。过程中的产量代理不作为 Agent 输入或任务成功条件。
- **范围**：本轮替换 Native L3 的土壤与冠层过程；L1、水分限制 WOFOST、物理设备账本、公开工具和统一时钟沿用现有实现。原版施肥、病虫、逐时灌溉、播深出苗和收获损失过程未移植。成熟后的粮食水分也仍由 2.0 计算。
- **复现**：Native L3 引擎身份为 `fairy_legacy_soil_canopy_soybean` 版本 3，快照 schema 2。两层储水和土温写入同一权威快照，日结不维护平行引擎副本。旧 Native L3 快照使用原冻结版本恢复。重新生成的 normal 阶段日历日期不变；参考哈希纳入移植源码。旧数值策略未重新训练或验收。

## 对照结果

| 同场景对照 | 零灌溉最低根区 VWC | 固定补水最低根区 VWC | 安全入库干粮：零灌溉 → 补水（kg） |
| --- | ---: | ---: | ---: |
| normal（无补水组） | 0.306 | — | 7894.04 |
| R1 停雨 | 0.230 | 0.274 | 7894.04 → 7894.04 |
| R5 停雨 | 0.237 | 0.275 | 7894.04 → 7894.04 |
| R1 + R5 停雨 | 0.167 | 0.246 | 7741.86 → 7894.04 |

用场景中点每次 20 mm；七组全部完成收储和严格回放。单段停雨影响土壤观测但未触发原版冠层水胁迫；双段出现累积亏缺。另有独立较长旱期探针：相同初态和天气下，0、旱期 10、旱期 20 mm 的成熟毛干粮分别为 290.12、296.31、302.78 g/m²；季初用同样 20 mm 为 296.76 g/m²。高产量冲击原固定验收脚本的拖车容量，固定验收改为逐批收储，约束不放宽。零 ET0、有光照且供水充分时恢复正常生长。所有结果均为仿真对照，不能据此断言田间产量或最优用水。

另以本地原版模块运行 85 个业务日：给两边相同水力参数、原版估算的 ET0、阶段和密度，逐日核对两层储水、LAI、生物量及成熟籽粒，均在 `1e-10` 绝对误差内一致。这个对照验证移植的两个过程，不代表两代项目的全套场景等价。

## 历史场景新增能力

当前 Native L3 引擎版本为 4，后端快照 schema 为 3。场景可在 `SeasonSpec.ponding_zones` 声明保水与自然退水参数，逐垄快照记录积水、工程排水和作物累计受涝天数。未配置的垄没有表面蓄水。冷春场景显式绑定种床传感器，播种前后检查已结算的表层土温。参数、历史对照与复现命令见[历史天气试点](../../../../../evaluate/scenarios/HISTORICAL_PILOT.md)。

Native L3 版本 5、后端快照 schema 4 增加可选病虫压力。日结 kernel 来自同一本地 `test_Knowledge` 快照的 `fairy/physics/biotic_pressure_engine.py`，原文件 SHA-256 为 `c359b2a9d49f2d88a61f0c02132908650198d2e512d1872becca4c7462551d27`。运行时从权威快照读取病虫压力、残效和待结算处置，使用场景声明的压力输入，禁用杂草增长。原模型的压力系数接入现有冠层生长及虫害叶面积损伤过程。默认场景的病虫模块处于禁用状态。

Native L3 版本 6、后端快照 schema 5 新增可选的落种缺口和补种苗群。补种使用原冠层和积温过程，原苗和补种苗分别推进，以占地比例汇总作物覆盖和粮食质量。未启用漏播配置时，每垄只有一个苗群。
